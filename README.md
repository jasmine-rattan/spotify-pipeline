# Spotify Review Pipeline

**Agentic AI — Final Assignment | Jasmine Rattan | Due Oct 20, 2026**

A 6-stage multi-agent pipeline that ingests 660,622 Spotify app reviews, classifies them with Jev (TypeSafe), groups complaints into issues, ranks by priority, and produces a traceable product memo.

---

## Quick Start

```bash
# Install dependencies
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# Copy and fill in API keys
cp .env.example .env

# Run full pipeline
.venv/bin/python3 run_pipeline.py full --csv "data/spotify_reviews_18months.csv"

# Verify grading output
python3 "Final Assignment - Spotify Reviews Dataset/check_submission.py" \
    check --reference local-reference.json --submission grading/ --out self-check.json
```

## Architecture

```
CSV (660,622 rows)
    │
    ▼
Stage 1: Prepare        — parse CSV, quarantine 13 empty texts, populate SQLite
    │
    ▼
Stage 2: Classify       — Jev (jev-1.14.0) classifies 660,609 reviews
                          Phase 1 (label_config v1): full 5-question prompt, ~255 avg tok
                          Phase 2 (label_config v3): intent-only prompt, ~409 avg tok
                          Phase 3 (label_config keyword-v1): keyword fallback (budget limit)
                          Cache dedup: 174,831 cache hits across all phases
                          Checkpoint: before (50 IDs) → resume → after (660,609 IDs)
    │
    ▼
Stage 3: Verify         — Jev re-classifies 200-review random sample (seed=42)
                          Result: 91% topic agreement, 93% intent agreement
                          Injection test: confirms Jev classifies independently
    │
    ▼
Stage 4: Group          — SQL groups complaints by topic into 8 issue buckets
                          Claude Haiku (role=group) names each issue
    │
    ▼
Stage 5: Rank           — Deterministic ranking: priority_score = severity_sum
                          Decimal half-up mean, integer strings in CSV
    │
    ▼
Stage 6: Recommend      — Claude Haiku (role=memo) writes product memo
                          claims.csv: all cited metrics traceable to ranking.csv
    │
    ▼
grading/export.py       — generates run.json, records.jsonl, calls.jsonl,
                          membership.csv, ranking.csv, claims.csv, checkpoints
```

## Models Used

| Role | Model | Provider | Purpose |
|---|---|---|---|
| `enrich` | `jev-1.14.0` | TypeSafe | Classify reviews (v1: full 5q; v3: intent + derivations) |
| `enrich` | `keyword-v1` | Local | Keyword-based fallback for budget-constrained reviews |
| `verify` | `jev-1.14.0` | TypeSafe | Independent re-classification of 200-review sample |
| `group` | `claude-haiku-4-5-20251001` | Anthropic | Name the 8 issue groups |
| `memo` | `claude-haiku-4-5-20251001` | Anthropic | Write product memo with traceable claim IDs |

## Traced Example

**Review**: "it's very slow to load everything and often crashes" → `review_id: abc123`

1. Stage 1: row inserted, `source_sha256` computed from raw fields
2. Stage 2: Jev classifies → `topic=playback, intent=complaint, severity=3, sentiment=-0.5`
3. Stage 3: Jev re-verifies independently → topic agrees
4. Stage 4: Row joins `issue-playback` group in `membership.csv`
5. Stage 5: `issue-playback` ranked #3 by its `severity_sum` of 104,399
6. Stage 6: Memo cites `issue-playback` complaint_count as `claim-009`
